
Standard queues focuses more on throughput i.e consuming as many messages as possible in a span of time without worrying about ordering and duplication. They have the atleast once delivery guarantee in place using retries

FIFO queues maintain ordering and removing duplicate message in the expense of throughput

in FIFO queue messages are grouped by messageID and messages with the same messageID are delivered in the exact order they were sent
only one consumer can process message from that group at a time
FIFO queue also uses MessageDeduplicationId to find duplicates within the time range of 5 minutes
FIFO queue handles 300 messages per second, or 3,000 with batching (10 messages per API call)
